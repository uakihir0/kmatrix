# kmatrix (Swift Package)

kmatrix is a Matrix protocol client library for Kotlin Multiplatform. This is the Swift Package Manager distribution for iOS and macOS.

## Installation

Add the following to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/uakihir0/kmatrix-spm.git", from: "0.0.1")
]
```

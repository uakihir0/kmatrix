# kmatrix (Swift Package)

kmatrix は Kotlin Multiplatform 向けの Matrix プロトコルクライアントライブラリです。これは iOS と macOS 向けの Swift Package Manager ディストリビューションです。

## インストール

`Package.swift` に以下を追加してください:

```swift
dependencies: [
    .package(url: "https://github.com/uakihir0/kmatrix-spm.git", from: "0.0.1")
]
```
